01

已經可以這樣用

下面每一項都是現在就能用的,不是路線圖。

📋剪貼簿即送

授權一次後,開 App 就看到剪貼簿的反灰預覽 — 文字或圖片縮圖 — 按「⚡即送」直接出門。開始打字,按鈕自動變「送出」。

📤分享面板直送Android

裝成 App 後,任何 App 按「分享」選 BentoDrop,背景自動加密送出,連畫面都不用操作。

🔔通知就是入口

通知直接顯示內容,附「複製」按鈕;是 https 連結就多一顆「開啟」。鎖定畫面不想被看到?每台裝置可各自關閉預覽。

📷照片自動瘦身

圖片先壓縮(長邊 2048、WebP)再加密,EXIF 與 GPS 位置自動剝除。要傳原檔也可以,會先警告你。

🤝加好友互送

掃 QR、按確認,就能和家人互送。用對方的公鑰加密,解除好友立刻擋下來訊。對方看不到你的裝置名稱。

🔑12 個字救回一切

還原碼用 BIP39 標準 12 詞,可複製、下載、列印、產 QR;還原時拍張 QR 照片就能匯入,打錯字當場抓出來。

🤖腳本也能推

NAS 備份完成、CI 建置結束 — 一行 curl 或附帶的 CLI 就能推到你的手機。token 只能發不能讀,外洩也看不到任何內容。

🗑️過期自動清空

預設 7 天自動刪除(可調 1/30 天),隨時可手動刪,所有裝置同步消失。明文模式的訊息最多只留 24 小時。

02

裝成 App,通知才可靠

BentoDrop 是 PWA:不經過商店、沒有安裝包,從瀏覽器直接「裝」。裝了之後有推送通知、出現在分享面板(Android),體驗和原生 App 一樣。

按下去就裝好,不用進商店

🤖 Android(Chrome)

  1. 用 Chrome 開啟 bentodrop.ai-apps.work
  2. 畫面上會出現「安裝」提示,或按右上 ⋮ → 安裝應用程式
  3. 開啟 App,在設定按「啟用本機通知」

🍎 iPhone / iPad(Safari)

  1. 用 Safari 開啟 bentodrop.ai-apps.work
  2. 按底部中間的分享鈕 ⎋(方框加向上箭頭)
  3. 往下捲,點 加入主畫面 → 加入
  4. 之後一律從主畫面圖示開啟,再到設定按「啟用本機通知」

iOS 一定要「加入主畫面」才有推送通知,在 Safari 分頁裡開是收不到的。iOS 支援目前標示為實驗性。

💻 電腦(Chrome / Edge)

  1. 開啟 bentodrop.ai-apps.work
  2. 點網址列右側的安裝圖示(螢幕加向下箭頭),或 ⋮ → 安裝
  3. 安裝後它就是一個獨立視窗的 App

速度是設計決策,不是效能指標

  • 即送

    剪貼簿有東西就先擺好。開 App 看到的第一眼就是預覽和一顆「⚡即送」。點預覽可以改成手動編輯 — 你永遠知道按下去會送出什麼。

  • 兩跳

    短文字不落地。2 KB 以內直接塞進推送封包,從按下到另一台震動只有一跳,沒有上傳再下載這回事。

  • 預設

    不問你要送給誰。預設送到自己的全部裝置;要送給好友,收件人選單選一下就好,不擋在路上。

  • 回執

    逐台打勾取代進度條。每台裝置各自打勾,比一根不知道跑到哪的長條有訊息量。

04

腳本推送:Pushbullet 留下的位子

在設定頁建立 API token(只能發、不能讀、可隨時撤銷)。兩種模式,取捨標得清清楚楚。

加密模式 — token 只拿公鑰

# repo 附的零依賴 CLI(Node 18+),內容用你的身分公鑰加密
BENTODROP_URL=https://bentodrop.ai-apps.work \
BENTODROP_TOKEN=bd_xxx \
node cli/bentodrop-push.mjs "建置完成 ✓"

token 外洩的後果只有「能發垃圾訊息」— 讀不到任何內容,包括它自己發過的。

明文模式 — 一行 curl 就好

# 建 token 時要勾「明文模式」;收件匣會標「未加密」,24 小時後自動刪
curl -X POST https://bentodrop.ai-apps.work/api/push \
  -H "Authorization: Bearer bd_xxx" \
  -H "content-type: application/json" \
  -d '{"text":"每日備份完成,共 42 GB"}'
05
